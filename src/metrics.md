Resource Utilization
= Actual Hours / Available Capacity

Planned Utilization
= Planned Hours / Available Capacity

Budget Variance
= Actual Spend - Planned Spend

Budget Variance %
= (Actual Spend - Planned Spend) / Planned Spend

On-Time Milestone %
= On-Time Completed Milestones / Completed Milestones

Hour Variance
= Actual Hours - Estimated Hours

Hour Variance %
= (Actual Hours - Estimated Hours) / Estimated Hours

Cycle Time
= Completion Date - Start Date
